Fifteen R source snapshots were recovered by matching the historical Phase 14D staged SHA256 records, with local syntax checks reported as 15/15 passed. The supplied source bytes match the prepared Phase 15D manifest. This verifies staged-source provenance, not execution of every stage. The standalone C++ routing engine was reconstructed from the embedded R source and matches the checksum of the recovered Phase 15C candidate. The original Phase 8D historical engine manifest has not been independently reconciled.

Original CRLF line endings are preserved. Do not normalize these files if verifying hashes. Verify from the repository root using the paths in Phase15D_source_SHA256.csv. The scripts expect the original Windows directory structure, saved upstream inputs, historical manifests and installed dependencies. They may write outputs or install dependencies when executed; use an isolated working copy. No study scripts were run during this deposit update. Earlier pipeline stages and intermediate datasets are not fully included. No rendered figures or manuscripts are included.

The earlier code/reference copies are retained as historical reference material and are superseded for these 12 overlapping phases by the recovered snapshots.
